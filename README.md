# 오늘의 록 — 1차 버전

현재 날씨와 사용자가 선택한 기분을 조합해 실제 록 음악 세 곡을 추천하는 웹앱입니다.

## 실행 방법

1. VSCode에서 `today-rock` 폴더를 엽니다.
2. `index.html`에서 마우스 오른쪽 버튼을 누릅니다.
3. **Open with Live Server**를 선택합니다.
4. 위치 권한을 허용하면 현재 위치의 날씨를 사용합니다. 거부하면 서울 날씨를 사용합니다.

## 파일

- `index.html`: 화면 구조
- `style.css`: 반응형 디자인
- `script.js`: 날씨 API, 음악 데이터, 추천 로직
- `images/concert-background.jpg`: 필터 처리한 전체 배경 사진

## 현재 기능

- Open-Meteo API로 현재 날씨 조회
- 위치 권한 거부 시 서울을 기본값으로 사용
- 여섯 가지 기분 선택
- 날씨와 기분에 따라 실제 발매곡 세 곡 추천
- YouTube 검색 링크 제공
- 곡별 주제, 정서·분위기, 추천 이유 제공
- Genius 가사 검색 버튼 제공
- 모바일 1열·데스크톱 3열 반응형 화면
